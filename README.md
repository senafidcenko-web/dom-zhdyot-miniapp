# Дом ждёт — Telegram Mini App

Мобильное приложение-каталог животных, которым ищут новый дом. Проект подготовлен как отдельный frontend prototype без backend: карточки и избранное сохраняются локально в браузере/WebView.

## Запуск локально

Откройте `index.html` в браузере или запустите любой статический сервер из этой папки, например:

```sh
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`. Для Telegram Mini App понадобится доступный по HTTPS адрес; GitHub Pages, Cloudflare Pages или собственный HTTPS-хост можно подключить после отдельного решения о публикации.

## Возможности

- Карточки кошек и собак, фильтр по виду, переключение кнопками и свайпом.
- Избранное с сохранением в `localStorage`.
- Контактная ссылка «Написать об этом животном».
- Добавление и изменение пользовательских карточек, в том числе загрузка фотографии с устройства.
- Мобильная навигация, safe-area отступы, клавиатурные стрелки и Telegram WebApp SDK.

Демонстрационные карточки и изображения в стартовом наборе — примеры. Для рабочего каталога их следует заменить проверенными данными и фото. Сейчас пользовательские карточки локальны для устройства и не синхронизируются между людьми. Для общего каталога нужен backend/API и проверка прав редактора.

## Публикация через GitHub Pages и подключение к Telegram

Для текущей статической версии API и токен бота не требуются. GitHub Actions публикует сайт из корня репозитория по адресу:

`https://senafidcenko-web.github.io/dom-zhdyot-miniapp/`

После появления успешного workflow откройте `@BotFather` и выполните: `/mybots` → выберите `@AHelpingPawbot` → **Bot Settings → Configure Mini App** → включите Mini App и вставьте указанный HTTPS URL. Для кнопки меню отправьте `/setmenubutton`, выберите бота, задайте текст `Найти питомца` и тот же URL. Ссылку можно открыть в браузере для проверки.

В проект уже добавлен GitHub Actions workflow для GitHub Pages. Первый запуск публикует сайт после включения Pages для репозитория с источником **GitHub Actions** в Settings → Pages.

### Ограничения прототипа

Контакты открываются как `t.me`, `tel:` или `mailto:` ссылки. Telegram `initData` пока не отправляется на сервер, поскольку backend не входит в этот прототип. Не добавляйте приватные данные в демонстрационные карточки.
